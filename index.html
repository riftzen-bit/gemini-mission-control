⚡ Quick Installation

Mission Control hooks directly into your local Gemini CLI workspace. No external servers required.

1

Clone the Repository

Clone this repository directly into your Gemini extensions folder or project workspace.

# Navigate to your workspace
$ git clone https://github.com/riftzen-bit/gemini-mission-control.git
2

Launch the Swarm

Open your terminal, start the Gemini CLI, and invoke the Mission Controller command.

$ gemini /enter-mission
🚀 AUTONOMOUS WORKSPACE ACTIVATED. SYSTEM GUARDRAILS ENGAGED.

# Give the swarm a complex task:
> Build a JWT auth system and update the UI. Run tests when done.
3

Exit and Regain Manual Control

When the task is perfectly executed and validated, exit the loop.

$ gemini /exit-mission
🛑 EXITED AUTONOMOUS WORKSPACE. SYSTEM RESTORED.

🧠 The Swarm Architecture

Mission Control divides labor to ensure high performance and absolute safety. No single agent holds all the keys.

The Architect

🗺️ Orchestrator

Analyzes your request and breaks it down into a highly optimized, parallel execution schedule. Enforces strict file-level isolation.

The Engineer

🛠️ Worker

Executes surgical code changes. Can run package managers (`npm install`) but is physically blocked from running tests to prevent "marking its own homework".

The Auditor

🛡️ Validator

A ruthless QA engine. Runs compilers, linters, and tests. If a build fails, it kicks a forensic report back to the Worker to self-heal.

🔒 Hardware-Level Guardrails

Giving AI write access to your production code is terrifying. We built a mathematically secure perimeter around it.

  • GATE 1
    Mandatory Backup Protocol
    The Orchestrator is forbidden from planning code changes until it schedules a Git branch or backup creation.
  • GATE 2
    Anti-Race Condition Lock
    Workers code in parallel, but Validators run strictly sequentially. Multiple test suites will never collide and corrupt your build folders.
  • ABORT
    The Circuit Breaker
    If a specific task fails validation 3 times consecutively, the system pulls the plug. No infinite loops. No wasted tokens.

Designed for the Gemini CLI Ecosystem. Do No Harm. Verify Everything.
